PASTA DO DASHBOARD (Fluxo de Caixa Realizado)

Arquivo: BASE_FLUXO_DE_CAIXA_REALIZADO.xlsx
Abas lidas: Contas a Receber (Realizado), Contas a Pagar (Realizado), INVESTIMENTO,
Plano de Naturezas e CONTA_BANCARIA (colunas BANCO, AGENCIA, CONTA e CLASSE; NOME é opcional).

COMO ATUALIZAR
1. Edite a planilha no seu computador e salve com o MESMO nome.
2. No GitHub: abra esta pasta (dados/dashboard) > Add file > Upload files > envie a planilha
   (ela substitui a anterior) > Commit changes.
3. Aguarde cerca de 1 minuto, abra o site, entre como admin, vá em Dashboard e clique em
   "Importar da pasta". O painel passa a mostrar o último ano e a Visão executiva com Mês = Todos.

Também é possível usar o botão "Upload" para enviar uma planilha direto do computador
(fica guardada só no navegador de quem fez o upload).

ATENÇÃO: o repositório publicado no GitHub Pages é público. Quem souber o endereço do arquivo
consegue baixá-lo, mesmo sem login. Se a planilha tiver dados sensíveis, use repositório privado
(o GitHub Pages privado exige plano pago) ou prefira o botão "Upload".
